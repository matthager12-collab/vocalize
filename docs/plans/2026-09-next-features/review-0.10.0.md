## Residual risk

- **Owner-present verification is the only thing standing between this branch and a release.** Nothing in it can be closed by an agent; see the two open critical rows above.
- **`--cleanup` writes dictated text to Claude Code's own session log in plaintext, on disk, indefinitely**, once a user opts in. This is now documented rather than fixed — there is no code mitigation, only an accurate warning and an off-by-default setting.
- **The microphone grant is bundle-wide, not vocalize-wide.** Any process running as the same user can launch Vocalize Recorder directly and use the grant. No code can prevent this; docs/dictation.md § Privacy names the mitigation (uninstall + revoke the grant).
- **No stale-tmpdir sweep for TTS temp directories** (see the open low finding above) — a disk-only leak on a hard kill, deferred to 0.11.0.
- **A version-1 `interrupted.json` from a machine that already ran a pre-review build of 0.10.0 is discarded on upgrade** (DEC-014f) — at most one read, at most an hour old, so the cost of the format bump is bounded.
