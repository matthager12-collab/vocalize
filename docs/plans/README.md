# Planning records

The folders here are planning records, kept for history. They are not
guides to the current version.

The `2026-09-*` plans and the notes in [`../research/`](../research/)
describe features that were later removed: cloud voices, keys, summaries
and note templates.

[`2026-11-local-only/`](2026-11-local-only/goal.md) is the plan for 1.0.0,
the local-only release.
